# Documentation

The site is built with [Zensical](<https://zensical.org/>) from `docs/site/` and `zensical.toml`. The Python API reference is generated by mkdocstrings from the package's docstrings and the compiled module's stub (`python/pq_glue/_pq_glue.pyi`).

```sh
just docs-serve   # build, serve and rebuild on change
just docs-check   # strict build, site checks, and the pages' examples as tests
```

`docs/scripts/check_site.py` checks that every page is in the nav, that internal links and anchors resolve, that every page has a description matching its llms.txt entry, and that every public name is in the API reference. `docs/conftest.py` runs each page's Python examples with pytest (`pytest docs`); a `pycon` block's output must match.

## Publishing

`.github/workflows/site.yml` builds the site on every push to master and publishes it to the `gh-pages` branch, served at [https://lmmx.github.io/pq-glue/](<https://lmmx.github.io/pq-glue/>). A pull request from this repository gets a preview under `pr-preview/pr-<number>/`, linked from a comment on the pull request and removed when it closes. Previews start once the repository's Pages source is set to the `gh-pages` branch.
